Requisitos de postulación

¿Quién puede iniciar este trámite?

Define las condiciones para postular. Un requisito excluyente bloquea el acceso al trámite si el ciudadano no lo cumple; los demás son informativos (se muestran, pero no impiden avanzar).

Flujo · máquina de estados

Estados y transiciones

Diseña los estados del trámite y cómo se pasa de uno a otro. Arrastra desde el punto de la derecha de un estado hacia otro para crear una transición. El sistema valida el flujo en vivo y bloquea la publicación si quedaría atascado. La doble validación (four-eyes) es una guarda opcional por transición para separar quién revisa de quién resuelve — no es un paso para publicar el tipo de trámite.

El certificado de estado y la notificación al ciudadano se disparan automáticamente en cada transición (núcleo legal).

Formulario ciudadano · por pasos

Lo que el ciudadano completa

Arma el trámite como un formulario por pasos. Cada paso puede ser un formulario, una carga de documentos, un pago, una firma o una página informativa. Arrastra para reordenar. Un paso puede mostrarse solo si se cumple una condición.
